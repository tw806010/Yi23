# 醫二三｜緊急工具包

## 簡介

- 「醫二三｜緊急工具包」是一個提供一般民眾使用的健康資訊與紀錄工具。
- 工具以清楚、容易操作的方式，整理中風徵象觀察、GCS 昏迷指數、生命徵象紀錄及急診檢傷資訊，協助使用者在需要時掌握初步資訊，並與醫護人員溝通。
- 本應用程式支援手機及電腦瀏覽器，也提供繁體中文、簡體中文及英文介面。
- 在支援的裝置與瀏覽器中，使用者可將網頁加入主畫面，方便再次開啟。

## 重要提醒與免責聲明

- 本工具提供一般健康資訊、初步觀察及資料整理功能，不能取代醫師、護理師、救護技術員或急診檢傷人員的專業判斷。
- 工具顯示的參考值、分類說明及評估結果，應配合患者實際狀況理解；不能只依本工具的結果決定是否就醫、用藥或延後就醫。
- 若患者出現無意識、呼吸困難、持續胸痛、大量出血、突然說話困難或症狀快速惡化等危急情形，請勿等待工具判讀，應立即撥打 `119`。
- 在急診中，實際檢傷級別、處理優先順序及等候時間，均由現場醫療人員依患者病情與醫療量能判斷。

## 功能列表與介紹

### 中風快速檢查

- 透過臉部、手臂及說話三項觀察，協助使用者留意可能的中風徵象。
- 臉部觀察：請患者微笑或露齒，觀察嘴角是否歪斜、左右表情是否對稱，或是否有單側臉部無力。
- 手臂觀察：請患者閉眼並將雙手向前平舉約 `10` 秒，觀察是否有一側無法抬起或明顯下垂。
- 說話觀察：請患者說「一」，觀察脣形與聲音；如情況允許，可再請患者重複簡短句子。留意發音含糊、用詞錯誤、無法說話，或無法理解簡短指令等情況。
- 每項觀察可記錄為「看起來正常」、「發現異常」或「無法判斷」。
- 發現疑似中風徵象時，頁面會提示立即撥打 `119`，並提醒準備症狀開始時間或患者最後一次看起來正常的時間等資訊。
- 檢查結果可製作成 `PNG` 圖片，方便使用者在本機儲存，作為紀錄與溝通參考。
- 即使檢查未發現明顯異常，若症狀持續、反覆出現或仍令人擔心，也不應因此延誤就醫。

### GCS 昏迷指數評估

- 依序記錄三項反應：睜眼反應（`E`）、言語反應（`V`）及動作反應（`M`）。
- 使用者依患者實際反應選擇符合的項目，系統會整理各項分數及評估結果。
- 若某一項反應無法評估，可選擇 `NT`；有項目為 `NT` 時，結果會註明該狀況，不會將三項分數加總成總分。
- 結果頁會顯示各項反應、評估時間及相關安全提醒，方便記錄或向醫療人員交接。
- 評估結果可製作成 `PNG` 圖片供本機儲存。
- 本功能是昏迷指數的紀錄輔助工具，評估項目與臨床判讀應由受過訓練的人員依實際狀況執行。

### 生命徵象測量與資料卡

- 可輸入患者年齡，並選擇以天、個月或歲為單位；系統依年齡對照各項生命徵象的參考區間。
- 年齡區間包含新生兒、嬰兒、幼兒及學齡前兒童、學齡期兒童，以及青少年與成人。
- 可記錄的項目包括：
  - 體溫，並可註明額溫、耳溫、腋溫或肛溫等量測部位。
  - 脈搏。
  - 呼吸次數。
  - 收縮壓與舒張壓。
  - 症狀備註，例如不舒服的位置、開始時間或症狀是否惡化。
- 建立資料卡後，系統會整理輸入值、參考資訊、量測時間及就醫溝通摘要，協助使用者向醫療人員說明。
- 生命徵象結果可製作成 `PNG` 圖片供本機儲存。
- 參考區間僅供初步對照。兒科參考資料表修訂於 `2013` 年；清醒或睡眠、活動、發燒及其他臨床狀況都可能影響數值。若有疑慮，應由醫療人員評估，不應因記錄或比較數值而延誤就醫。

### 急診檢傷分類資訊

- 以一般民眾容易理解的方式說明急診檢傷五級分類，讓使用者了解急診會依病情危急程度安排處理順序，而非單純按照到院先後看診。
- 頁面列出五個級別及代表性症狀，並提供可能的等候時間作為流程說明。
- 範例與等候時間僅供理解急診流程，實際檢傷結果及等候時間會依患者當下狀況、現場病情與醫療量能調整。
- 頁面提供就醫溝通清單，提醒使用者可主動整理：
  - 症狀開始時間。
  - 哪裡不舒服。
  - 不舒服的感覺或型態。
  - 不舒服多久了。
  - 慢性病。
  - 過敏史，包含食物及藥物。
  - 正在使用的藥物。
  - 症狀是否正在惡化。
- 也提醒使用者，在急診等候期間若出現胸痛、呼吸困難、意識改變、出血增加、疼痛加劇、新的無力或麻木、說話困難，或其他明顯惡化情況，應主動告知現場醫護人員。

### 結果圖片儲存

- 中風快速檢查、GCS 評估及生命徵象資料卡均提供「儲存結果圖片」功能。
- 使用者可將結果製作為 `PNG` 圖片並儲存至本機，供個人紀錄或與醫護人員溝通時參考。
- 圖片是紀錄用途，不能取代正式病歷、醫療診斷或專業交接。

### 語言選擇

- 介面提供繁體中文、簡體中文及英文三種語言。
- 使用者可透過頁面上的語言選單切換介面語言，方便不同語言使用者閱讀工具內容。

### 版本記錄

- 「版本記錄」頁面依日期整理應用程式的功能新增與更新內容，方便使用者了解版本進度。

### 關於作者與支持我們

- 「關於作者」頁面提供作者的 Instagram 與 GitHub 連結，點選後會另開視窗前往目標網頁。
- 頁面也提供「支持我們」連結，使用者可自行選擇是否前往支持頁面。

## 適用族群

- 想先了解常見急症觀察方式的一般民眾。
- 在家中照顧長者、兒童或其他需要協助者的家屬及照顧者。
- 希望整理生命徵象、症狀開始時間與病史資訊，以便就醫時清楚說明的人。
- 希望了解急診檢傷流程與五級分類原則的民眾。
- 需要以繁體中文、簡體中文或英文瀏覽工具內容的使用者。

本工具適合用來協助觀察與整理資訊；遇到緊急狀況時，請優先聯絡緊急救護服務並遵從專業人員指示。
