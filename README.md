# 醫二三｜緊急工具包

醫二三是一個為一般民眾設計的緊急健康資訊工具包，將常見的急症辨識、生命徵象紀錄與急診就醫資訊，整理成清楚、直覺且可在手機與電腦使用的操作頁面。

本工具的目標不是取代醫護人員、救護技術員或急診檢傷人員的專業判斷，而是在需要時協助使用者更快辨識狀況、整理資訊，並採取適當行動。

若出現無意識、呼吸困難、持續胸痛、大量出血、突然說話困難或症狀快速惡化等危急徵象，請勿等待工具判讀，應立即撥打 119。

## 目前功能

- 測量生命徵象
  可輸入體溫、脈搏、呼吸、血壓及症狀備註，並依量測部位整理體溫參考資訊，建立清楚的生命徵象資料卡與就醫溝通摘要。

- 急診檢傷分類
  以民眾容易理解的方式說明急診檢傷五級分類、可能等候時間與代表性症狀，協助理解急診依病情危急程度安排就醫順序的原則。

- 中風快速檢查
  透過臉部、手臂與說話三項觀察，協助辨識可能的中風徵象；發現異常時，會立即引導使用者撥打 119 並記錄重要資訊。

- GCS 昏迷指數評估
  依睜眼反應、言語反應與動作反應，記錄 `E`、`V`、`M` 三項資料；支援無法評估的 `NT` 狀態，並保留評估時間與交接資訊。

- 就醫溝通協助
  提醒使用者整理症狀開始時間、症狀位置與型態、慢性病、過敏史、正在使用的藥物，以及症狀是否惡化，協助向醫護人員清楚說明。

- 響應式 Web App
  可在手機與電腦瀏覽器使用，並支援加入主畫面；網站採新版快取策略，以降低使用者持續看到舊版內容的情況。

- 關於作者
  提供作者的 Instagram 與 GitHub 連結，使用者可另開視窗前往瀏覽。
